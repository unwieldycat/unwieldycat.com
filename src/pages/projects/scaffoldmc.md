ScaffoldMC is a server management panel for Minecraft that I've been working on
slowly for a bit over a year now. It is still in early development and not ready
for public use.

## Motivation

I built ScaffoldMC because I wasn't satisfied with the Minecraft server
management panels that were available, and I had for a while been interested in
building something like a Minecraft launcher. The final straw that led me to
start the project was the friction of the Minecraft server panel I currently
use. Third-party client launchers like Prism or Modrinth launcher are incredibly
user friendly, and it is trivial to do things like change the game version and
install mods with. Server panels, on the other hand, often leave you on your own
after you create the server, requiring you manually update servers, manually
manage mods, etc. ScaffoldMC intends to bring that ease of use to the server.

## Personal Remarks

Ideally I want this project to grow a community around it. Currently I'm focused
on getting the featureset and codebase in a good enough state so I can start
releasing alpha versions and make more iterative improvements to it. The biggest
struggle I have with the project right now is time; it is a pretty decently
sized project and I have a lot of ambitions for it, but I also have to balance
being a full time student on top of it. I'm hoping I can catch the eye of
likeminded people to be able to help out with the project at some point.
