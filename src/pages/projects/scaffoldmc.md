ScaffoldMC is a server management panel for Minecraft that I'm
working on. It is currently, still, in early development and not
ready fot public use, but I am working on it slowly but surely as I
get time to work on it.

## Motivation

I built ScaffoldMC because I wasn't satisfied with the Minecraft
server management panels that were available, and I had for a while
been interested in building a Minecraft launcher.
